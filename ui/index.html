Programmatic prompt optimization · Banking77

Can automatic optimizers write a better prompt than a person? Not on this task.

A bank gets customer messages like “my card hasn’t arrived” and needs to sort each one into one of 12 categories. We compared prompts written by hand with prompts generated by DSPy, TextGrad and AdalFlow, all running on the same small local model.

04 · Full report

Quality and cost.

The comparison report (deliverable 3): how good each prompt is, how long it is, and what the optimizer spent to find it.

The columns

  • Accuracy: share of messages right.
  • Macro F1: average quality across all 12 categories. Low if a prompt ignores some.
  • Prompt tokens: prompt length. Shorter is cheaper to run.
  • LLM calls, tokens: work the optimizer did to find the prompt.
